# TUFHelperLite 1.0.1

Fixes levels that failed to extract, or opened without their music, when the archive has long file names or Japanese, Chinese, Korean or other non-ASCII names.

- Read the original UTF-8 file names that Bandizip, 7-Zip and similar archivers store inside the ZIP. Names zipped on Chinese, Japanese or Korean Windows keep their characters, so levels find their song and image files again.
- When an archive has no stored UTF-8 names, choose the code page (Korean, Chinese GBK, Japanese Shift_JIS or UTF-8) that fits all of its names instead of always reading them as Korean. A broken byte no longer swallows the `/` or `.` after it.
- Shorten file and folder names only when they exceed the operating system's name or path length limits, keeping the file extension. Names the system accepts are left unchanged.
- On Windows, rename entries that use reserved names such as `CON`, invalid characters, or trailing dots and spaces.
- Show a clear error for levels uploaded as RAR or 7z archives instead of reporting a corrupt ZIP. These levels still need to be downloaded and opened manually.

Existing installations update automatically. Settings and downloaded levels are preserved. Levels that were downloaded before this release with broken file names can be deleted in Manage downloads and downloaded again.

Download `TUFHelperLite.zip` for a manual installation and verify it with `TUFHelperLite.zip.sha256`.
