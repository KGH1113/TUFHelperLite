# TUFHelperLite 1.0.2

Fixes level downloads and automatic updates failing on Linux with `The drive name does not exist`, most often when the game runs inside the Steam Linux Runtime.

- Check free disk space on the filesystem that actually contains the destination folder, instead of always using the system root.
- Apply the same check to level downloads, archive extraction, automatic updates and download folder moves.
- If free space cannot be measured, continue instead of stopping the download.

**Linux users on 1.0.1 or older need to install this release manually once**, because the old updater stops at the same error. Close the game, then extract `TUFHelperLite.zip` into the game's `Mods` folder and overwrite the existing files. Do not delete `Mods/TUFHelperLite` first, because it can contain your settings and downloaded levels. Later updates are automatic.

Other existing installations update automatically. Settings and downloaded levels are preserved.

Download `TUFHelperLite.zip` for a manual installation and verify it with `TUFHelperLite.zip.sha256`.
