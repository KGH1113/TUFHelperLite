# TUFHelperLite 1.0.0

TUFHelperLite now includes the ADOFAI-IPC SDK. The separate AdofaiIpc mod is no longer required after all installed IPC consumers have migrated. Existing 0.1.9 installations can receive this release through their normal automatic updater. Settings and downloaded levels are preserved.

Download `TUFHelperLite.zip` for a manual installation. It is also the single package used by both generations of automatic updater. Install the complete ZIP; the compatibility files in `Assets/AdofaiIpc` remain intentionally included for users upgrading from older installations.

The SDK is staged before Helper initializes. After initialization succeeds, Helper selects its SDK launcher for the next game launch and stops using the legacy IPC installer. A failed download, checksum or incomplete package leaves the active version available. A manual reinstall can also select the locally installed release while offline.

Validation covers the current updater, the actual updater and dependency shim from the published v0.1.9 ZIP, SDK file promotion, next-launch state, interrupted update recovery, checksum/path validation and preservation of user data. Unity game startup, cross-mod SDK discovery and operating-system file locks still require the supplied in-game migration scenarios.
